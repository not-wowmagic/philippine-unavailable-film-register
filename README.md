# Philippine Unavailable Film Register

A static status register for hard-to-find Philippine films, especially shorts and festival titles, plus a separate title index screened against digital catalogs.

Each record answers one question: **does a public copy exist, and if not, why not?**

The site is plain HTML, CSS and JavaScript. The verified records live in [`data/films.json`](data/films.json); the separate hard-to-find title index lives in [`data/hard-to-find.json`](data/hard-to-find.json). A dependency-free Node builder pre-renders the register, one page per record, and the full hard-to-find index. There is no backend and no database.

Routes:

- `/` — the register
- `/film/<id>/` — one record
- `/hard-to-find/` — the full 1,752-title index

## Deploy

The site deploys to **Cloudflare Pages** as a static site. `dist/` is generated by the build and is not committed.

### Cloudflare Pages, connected to GitHub

1. Push this repository to GitHub.
2. In the Cloudflare dashboard, open **Workers & Pages → Create → Pages → Connect to Git** and select the repository.
3. Use these build settings:
   - **Framework preset:** None
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
   - **Node version:** read from `.nvmrc` (Node 22; the build needs Node 18+)
4. Optionally set the build-time environment variable `SITE_URL` to the production origin, for example `https://philippine-unavailable-film-register.pages.dev` or your custom domain. When present, the build writes `sitemap.xml` and links it from `robots.txt`.
5. Deploy.

Every push to the production branch rebuilds the site. Pull requests get preview deployments.

### Manual deploy

```bash
npm run build
npx wrangler pages deploy dist
```

### What the build produces for Cloudflare

- `404.html` — served automatically for unknown paths.
- `_headers` — security headers and cache policy. HTML revalidates; hashed files under `/assets/*` are immutable for one year.
- `robots.txt` — always allows crawling; includes `Sitemap:` when `SITE_URL` is set.
- `sitemap.xml` — only written when `SITE_URL` is set.

The Content-Security-Policy is deliberately strict: scripts, styles, fonts and images are same-origin, plus inline speculation rules. If you add third-party scripts such as analytics or embeds, update the CSP in `scripts/build.mjs`.

There are no Functions, no database and no runtime environment variables. `data/` is build-time input and is not served. The site self-hosts its fonts, so there are no third-party font requests.

The build uses absolute paths (`/assets/...`, `/film/<id>/`) rooted at `BASE_PATH`, which is empty by default. Cloudflare Pages serves from a domain root, so leave it unset. Set it only when deploying under a subpath, for example `BASE_PATH=/repo-name npm run build`.

## The data model

`data/films.json` is an array of film records. Every record has the same shape. Unknown values are `null` and are rendered as **“unknown”** — never guessed.

```json
{
  "id": "example-film",
  "title": "Example Film",
  "original_title": null,
  "year": 2024,
  "type": "documentary",
  "director": "Example Director",
  "runtime_min": null,
  "festivals": [
    { "festival": "Cinemalaya", "year": 2024, "section": "Documentary" }
  ],
  "status": "unavailable",
  "cause": "never_distributed",
  "status_detail": "One-sentence public explanation of the status.",
  "quoted_reason": {
    "text": "A verbatim quotation.",
    "attributed_to": "The person or body quoted, and where it was quoted.",
    "source_url": "https://example.com/source"
  },
  "last_verified_screening": {
    "date": "2024-08-06",
    "venue": "Cinema 2, Ayala Malls Manila Bay, Quezon City",
    "source_url": "https://example.com/screening-source"
  },
  "known_copy": {
    "holder": "Production company or archive",
    "format": "digital / 35mm / etc.",
    "access": "not public / archive access / legal VOD"
  },
  "where_to_watch": [
    {
      "platform": "Example platform",
      "url": "https://example.com/watch",
      "note": "Region or access caveat, if any."
    }
  ],
  "sources": [
    {
      "url": "https://example.com/source",
      "publisher": "Publisher",
      "retrieved": "2026-10-31"
    }
  ],
  "confidence": "reported",
  "notes": "Research notes, including the availability search and any unresolved questions.",
  "availability_last_checked": "2026-10-31"
}
```

### Field notes

| Field | Rule |
| --- | --- |
| `id` | Lowercase slug, unique. Used in deep links (`#film-id`). |
| `title` | The title used on the site. |
| `original_title` | Original-language or alternate title, or `null`. |
| `year` | Integer or `null`. Do not infer a year from a festival edition. |
| `type` | `feature`, `documentary`, `short`, or `short documentary`. |
| `director` | Required. |
| `runtime_min` | Positive integer or `null`. |
| `festivals` | Array of `{ festival, year, section }`; `section` may be `null`. Empty array if none. |
| `status` | One of the six taxonomy values below. |
| `cause` | Required for `unavailable`; must be `null` for every other status. |
| `status_detail` | One-sentence public explanation. No speculation. |
| `quoted_reason` | Required for `banned` and `lost`. `null` otherwise if no quote is needed. |
| `last_verified_screening` | Required for `unavailable`; `null` if the film has no documented public screening. |
| `known_copy` | `null` if no archive, studio or private copy is recorded. |
| `where_to_watch` | Empty array if no legal streaming, VOD or archive access was found. |
| `sources` | At least one. Every entry needs a URL, publisher and retrieval date. |
| `confidence` | `confirmed`, `reported` or `unverified`. |
| `notes` | Research notes. Required, and should record the availability search. |
| `availability_last_checked` | Required extension to the supplied record shape. Every availability claim carries this date. |

`where_to_watch[].note` is optional. It is used for region locks and archive-access caveats.

## How to add an entry

1. **Check inclusion.** The film should have no current general legal access, or be a resolved case (a lost or banned film with a located copy). A film that is actively screening or legally streaming belongs in a note, not in the register.
2. **Establish the film.** Find a source for title, year, director and type. Add any documented festival history.
3. **Establish the status.** A screening, ban, withdrawal or located copy must be documented before a status is assigned.
4. **Check availability.** Search legal streaming, VOD, home video and archive catalogues. Record the date in `availability_last_checked`.
5. **Write the record.** Use `null` for anything unknown. Do not invent a date, venue, runtime or quote.
6. **Add sources.** Every `source_url` used for a quote or screening must also appear in `sources[]` with a publisher and `retrieved` date.
7. **Set confidence.** See the definitions below.
8. **Update the changelog.** If the status changed, add an item to `CHANGELOG` in `app.js` with a date and source.
9. **Validate.** Run `node scripts/validate.mjs`.
10. **Test the UI.** Check the new record in the cards, filters, search, detail dialog and deep link.

Adding a record is not a matter of filling a table. The evidence has to support the status. If it does not, leave the record out.

## The evidence bar

### Status definitions

The UI panel is the canonical presentation. The rules are:

- **banned** — regulator or court blocked exhibition. Needs a quotable decision, or a report quoting one.
- **withdrawn** — accepted or scheduled, then pulled before public screening. Needs a dated report.
- **unreleased** — finished or partly finished, never publicly exhibited.
- **unavailable** — screened at least once publicly, but no current legal way to watch it. Needs a documented screening **and** a checked-and-empty availability search.
- **lost** — no known copy in any archive, studio or private collection. Needs an archive or historian statement, not “I can't find it”.
- **found / partially_found** — a copy has been located; record where and when.

### Causes

`cause` applies only to `unavailable`:

| Value | Meaning |
| --- | --- |
| `never_distributed` | Screened publicly, but never commercially distributed. |
| `distribution_ended` | Formerly available, but the legal edition or stream has ended. |
| `rights_unclear` | Rights are unknown or disputed. |
| `archive_only` | A copy is held by an archive without public access. |
| `no_known_rights_holder` | No rights holder has been identified. |

### Quotes

Quotes must be **verbatim**. Use an ellipsis for an omission; never paraphrase inside quotation marks. Attribute the quote to a person or body and link the source. A report quoting a regulator or court is acceptable for `banned`; a paraphrase is not.

### Screening and availability

- A screening needs a date (or documented partial date), a venue, and a source.
- An availability claim needs a check date and a note about what was searched.
- A legal streaming, VOD, home-video or archive copy prevents `unavailable`. Use `found` or `partially_found` instead, and record where it is.
- A trailer is not a copy. An unauthorized full-film upload is not legal access and must never be linked.
- A negative finding is a result. It is not proof that no copy exists, and it is not a reason to use `lost`.
- When credible sources conflict, use the more conservative status and record the conflict. *Dyesebel* is the example: an archive statement says no copy survives, while a 2005 report describes a Thai archive print. It is filed as `unavailable`, not `lost`.

### The lost rule

Do **not** use `lost` for a film that merely has no streaming link. `lost` requires an archive or historian statement that no copy is known. Most films with no stream are `unavailable`, not lost.

This register deliberately leaves several films at `unavailable` rather than `lost` because the available sources do not meet this bar. That is intentional. The “no known copy” filter exposes the same fact without overstating it.

## Confidence

| Badge | Meaning |
| --- | --- |
| **confirmed** | The core status claim is supported by a primary, archive or regulator source. Examples: an archive holding, a regulator statement, a legal VOD listing. |
| **reported** | The core facts are supported by news reporting, festival pages or film databases, but not by a primary record for every claim. |
| **unverified** | The record relies on a forum, rumour or community database, or the identity of a circulating copy is unresolved. |

Availability searches are desk research. Even a `confirmed` record can change when a catalogue, region or archive policy changes.

## What is in this dataset

34 records, last checked **31 October 2026**.

The current snapshot has one `withdrawn` record (*Food Delivery*), one `partially_found` record (*Darna*, 1951), and no `unreleased` records. The remaining statuses are populated. The verified register is a status record, so it still includes titles that have been found; the hard-to-find index below is the filtered list.

### The hard-to-find public index

A separate section below the verified register lists **1,752 films** with a Wikidata item and the Philippines as their sole country of origin, after a digital-availability screen against JustWatch Philippines on **1 November 2026**. It is not part of the verified register and makes no status claim.

The screen started from **2,034 titles**. JustWatch Philippines listed an active streaming, free, ad-supported, rental or purchase offer for **282** of them; those were removed and recorded with their evidence in `data/digitally-available.json`. The remaining **1,752** had no active offer in the catalog. Titles with no year or no exact JustWatch match are retained, marked `unchecked`, and listed in `data/not-screened.json`; they are not evidence of availability or unavailability.

The hero index and filter rail both open it. The section stays hidden until one of them is pressed. It is searchable and paginated, with a **Show all titles** control that renders the full index in one table. Every row links to its Wikidata item (plus IMDb where available). It is deliberately separated from the verified cards: a title appearing there means only that no active digital offer was found in the JustWatch Philippines catalog, not that it is lost, banned or unavailable everywhere.

The filter rail button opens the section and scrolls to it. A **Close** button hides it again.

It is **not the 8,000+ estimate**. The estimate covers films shot on film stock, most of which have no public title record at all. The About section explains the gap and the archive work that would be needed to close it. The 8,000+ figure comes from [The Philippine Star, 17 August 2026](https://www.philstar.com/entertainment/2026/08/17/2549804/philippine-cinema-faces-urgent-preservation-challenge), citing Leo Katigbak of ABS-CBN Film Archives.

The hard-to-find index lives in `data/hard-to-find.json`; the full 2,034-title source index remains in `data/unverified.json`; the removed titles are in `data/digitally-available.json`; the unmatched subset is in `data/not-screened.json`; and the per-title screen is in `data/availability-audit.json`.

The screen is a point-in-time catalog check, not a worldwide rights audit. JustWatch does not index every archive holding, film festival, DVD release or unofficial upload. A title missing from the hard-to-find list had an active JustWatch Philippines offer; a title in it without an exact match is marked `unchecked`. Neither is a declaration that a copy is available or unavailable everywhere.

## Seed notes and exclusions

### Researched but excluded: *Bloom Where You Are Planted* (2025)

This was not dropped for lack of sources. It is excluded because it remains in active public circulation in 2026 and therefore does not meet the register's inclusion test.

Sources record:

- [Cinemalaya 2025](https://www.cinemalaya.org/bloom-where-you-are-planted/), where it won Best Film; the festival lists it at 82 minutes.
- A [24 September 2026 campus screening](https://astig.ph/bloom-where-you-are-planted-cinemalaya-documentary-pup-bantayog-2026/).
- A [27 October 2026 screening at UP Manila](https://www.facebook.com/altermidya/posts/bloom-where-you-are-planted-screening-sa-up-manila-october-27-2026-tuesday-100-p/1631495252350950/).

If those screenings end and no legal streaming or archive access appears, it can be added as `unavailable` with a fresh availability check.

### *Aurora*: 2008 or 2009?

The seed lists 2008. PEP.ph (20 January 2009), IMDb and MUBI date the film to 2009. The record uses **2009** and notes the discrepancy. The X rating was given twice; the 19 January 2009 UP Cine Adarna premiere took place where MTRCB ratings did not apply.

### *Pusang Gala*: title

The seed title “Pusang Gala” refers to **Mga Pusang Gala**, released internationally as **Stray Cats**. The record uses the Filipino title and records the English title as `original_title`.

### *Lost Sabungeros*: why not `withdrawn`?

It was withdrawn from Cinemalaya 2024, but it later screened at QCinema (9 November 2024) and on a 2026 campus tour. The current status is therefore `unavailable`; the withdrawal is recorded in the changelog.

### *Orapronobis*: why not `banned`?

Secondary sources describe a censors' ban that was never formally lifted. No quotable regulator or court decision was located. The record is filed as `unavailable` rather than `banned`. If a quotable decision is found, change the status and add a changelog entry.

### *Agent 00*, *Batman Fights Dracula*, *Scotch…*, *Milagro sa Porta Vaga*: why not `lost`?

All four have no located copy in the sources checked. None has an archive or historian statement meeting the lost evidence bar. They are filed as `unavailable` with `known_copy: null` and the “no known copy” filter exposes that fact. This is the conservative choice.

### *Live Show*: found, but still banned in the Philippines

The 2001 Malacañang appeals committee permanently banned the film from Philippine theaters and revoked its MTRCB permit. A legal uncut edition is now listed for rent/purchase on Amazon US. The record is `found` because a legal copy has been located; the ban remains on record, and the US region caveat is in the where-to-watch note.

### Expansion notes: from 14 to 34 records

The second research pass added every title that cleared the same evidence bar:

- **Banned:** *Butakal: Sugapa sa Laman* (Supreme Court/MTRCB record), *Ganito Tayo Noon, Paano na Tayo Bukas?*, *Ayos Ka?* (2010 MTRCB X ratings), and *Dear Satan* (final X rating, 2024).
- **Partially found:** *Darna* (1951), where a 40-minute, silent, incomplete print in Thailand is documented by Wikipedia and a contemporaneous 2005 i-Witness account.
- **Found:** *Paglaki Ko, Gusto Kong Maging Pornstar* (Prime Video rental despite an X rating for cinemas).
- **Withdrawn:** *Food Delivery, Fresh from the West Philippine Sea* (pulled from CinePanalo two days before its premiere).
- **Unavailable historical titles:** *Tiniente Rosario*, *Secreto de Confesión*, *La Venganza de Don Silvestre*, *Ang Batang Tulisan*, *Korea* and *Pinagbuklod ng Langit*. Film histories describe several as lost, but none has the archive or historian statement required for `lost`; they are filed as `unavailable` with `known_copy: null`.
- **Dyesebel (1953)** is a deliberate conflict case: ABS-CBN Film Restoration says no copy survives, while a 2005 i-Witness account reports a Dyesebel print in a Thai archive. It is `unavailable`, with the reported print recorded as an unconfirmed `known_copy`, not `lost`.
- **More recent festival titles:** *The Hearing*, *Kono Basho* and *Under a Piaya Moon* are recorded as `unavailable` after their 2024 festival/theatrical runs, with no legal streaming listing found. *Ang Mabuhay para sa Masa* (2006) is recorded as `banned` after the MTRCB X rating was upheld by the Court of Appeals.

This is still not an exhaustive all-time filmography. It is the set of titles in the research queue that could be sourced and classified without guessing.

## Validation

The validator checks:

- JSON shape and unique ids.
- Required fields and enums.
- `cause` only on `unavailable`, and required there.
- A `quoted_reason` on every `banned` and `lost` record.
- A documented screening on every `unavailable` record.
- `lost` records have no `known_copy`.
- `found` records have a `known_copy` or a `where_to_watch` entry.
- At least one source per record, each with an http(s) URL, publisher and retrieval date.
- Quote and screening source URLs appear in `sources[]`.
- Dates are valid and not in the future.
- `availability_last_checked` is present on every record.
- The full source index (`data/unverified.json`) has a valid count, unique Wikidata ids, source URLs and year/IMDb fields.
- The hard-to-find index has valid retained/removed/unmatched counts, per-title availability dates and source URLs.
- The digitally-available audit file has an available JustWatch check for every removed title.

## Design and technology

- Plain HTML, CSS and JavaScript. No framework, bundler or runtime dependency.
- Verified register: one JSON data file, `data/films.json`.
- Hard-to-find index: `data/hard-to-find.json`, loaded on demand and never mixed into the verified records.
- Full source index: `data/unverified.json`; removed titles and evidence: `data/digitally-available.json`; unmatched titles: `data/not-screened.json`; per-title screen: `data/availability-audit.json`.
- Native `<dialog>` detail view with deep links (`#film-id`).
- Filters: status, cause, decade, type, festival.
- Search across title, original title and director.
- Toggles: quotable reason, no known copy, recently checked.
- Empty results are handled with a clear state and a reset control.
- The taxonomy panel is static HTML so it remains visible even if the data fails to load.
- Accessibility: skip link, labelled controls, `aria-pressed` filter chips, `aria-live` result counts, focus restoration, reduced-motion support.
- No analytics, cookies or tracking.

## Limitations

This is desk research, not an archive visit or a rights-holder interview. Availability can vary by country, and a platform listing can disappear. Some release dates and runtimes come from IMDb or Letterboxd and are marked with lower confidence. Archive access may require institutional affiliation. A negative availability finding is dated and not exhaustive.

The pre-war survival picture is still being revised — CINEMATEK's 2025 identification of *Diwata ng Karagatan* is a good example of why “lost” must be an evidence claim, not a search result.

---

## No piracy

No unauthorized full-film uploads are linked. When unofficial copies are mentioned in notes, they are described but not linked. `where_to_watch` is reserved for legal streaming, VOD, home-video or archive access. Trailers are not treated as the film.

If you find a legal copy or a better source, add it, update `availability_last_checked`, and record the change in the changelog.
